# Healthcare Clinical NLP

## Overview

This repository demonstrates Natural Language Processing (NLP) techniques applied to clinical healthcare text.

The project focuses on preprocessing unstructured clinical notes and preparing them for downstream machine learning and healthcare AI applications.

## Topics Covered

- Clinical Text Preprocessing
- Clinical Abbreviation Expansion
- Tokenization
- Text Normalization
- Healthcare NLP Fundamentals
- Word Embeddings
- Transformer Foundations
